الموقف 3
**الفئة:**الفئة: cPanel
الـ prompt: "عايز أرفع مشروع Laravel على cPanel، إزاي أظبط الدومين يفتح على مجلد public؟"
الرد (الجزء الغلط): "اذهب لـ Domains → Manage، وغيّر Document Root من public_html إلى laravel-project/public" — بيفترض إن ده متاح دايمًا للدومين الأساسي
الغلط بالتحديد: تغيير Document Root للدومين الأساسي (Main/Primary Domain) غير متاح من واجهة cPanel أصلاً في أغلب استضافات shared hosting؛ الخيار ده متاح بس للـ addon domains والـ subdomains. الموديل قدّم الحل ده كأنه الخطوة الأساسية والمضمونة، وعامل الحل البديل (نقل ملفات public) كخيار ثانوي "أقل تفضيلًا"، رغم إنه غالبًا هو الحل الوحيد المتاح فعليًا لمعظم المستخدمين
الدليل: توثيق cPanel الرسمي (support.cpanel.net) — "You cannot change the document root directory for the Main Domain"
السبب المحتمل: تعميم زائد — الموديل عمّم سلوك متاح للـ addon domains على الدومين الأساسي كمان، من غير تفرقة بين النوعين
